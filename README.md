An Electronics Store Website

A responsive electronics store website built with HTML, CSS and JavaScript.

Features:
-12 products in 4 categories: laptops, phones, accessories and gaming
-Search, category filter and sorting (price and name)
-Product details window
-Shopping cart with quantity controls, total price and simulated checkout
-Sign up, login and logout
-Wishlist
-Light and dark mode
-Deals countdown, contact form and newsletter form
-Responsive layout for desktop, tablet and mobile

Cart, accounts, wishlist and theme are saved in the browser using Local Storage.

JavaScript Concepts Used

Arrays and objects, functions, array methods (forEach, filter, find, some, sort), DOM manipulation, template literals, event listeners and delegation, form validation, Local Storage with JSON, and setInterval for the countdown.

Notes

This is a front-end demo with no backend. Passwords are stored unencrypted in Local Storage, the forms do not send data anywhere, and checkout is simulated.
